# 句式库

句式只能用于表达源材料已经支持的内容。不要为了让文字“像公文”而补入会议没有形成的判断、意义、成绩或要求。句式选定后，按 `纪要语言自然化.md` 检查是否出现套话堆叠、同构句和无事实支撑的评价。

## 开头句

- `〔年月日〕，〔主持人〕在〔地点〕主持召开〔会议名称〕，听取了〔事项〕情况汇报，审议了〔文件名称〕，研究了〔事项〕。现纪要如下：`
- `〔年月日〕，〔主持人〕主持召开〔事项名称〕专题会议，研究〔事项〕有关问题。纪要如下：`
- `〔年月日〕，〔主持人〕主持召开办公会议，研究〔事项〕。纪要如下：`
- `〔年月日〕，〔主持人〕主持召开〔事项名称〕协调会议，研究协调〔问题〕。现纪要如下：`

## 议题句

- `会议听取了〔单位〕关于〔事项〕情况的汇报。`
- `会议审议了《〔文件名称〕》。`
- `会议研究了〔事项〕有关问题。`
- `会议传达学习了〔会议、文件、讲话〕精神。`
- `会议集中学习了〔法规、条例、办法〕。`

## 判断句

- `会议认为，〔对事项的明确判断〕。`
- `会议指出，〔当前情况、主要问题或工作判断〕。`
- `会议强调，〔需要突出把握的原则、条件或重点〕。`
- `会议要求，〔责任主体〕〔具体动作〕。`

判断句必须有源材料中的对应判断。不要自行添加“事关全局、意义重大、问题导向、落到实处”等通用表述。

## 结论句

- `会议原则同意〔方案、意见、事项〕。`
- `会议原则同意该方案，由〔牵头单位〕根据会议讨论意见修改完善后按程序报批。`
- `会议明确，由〔牵头单位〕牵头，〔配合单位〕配合，抓好后续工作落实。`
- `会议决定将〔事项〕按程序提交〔机构或会议〕审议。`仅在材料明确会议已形成该程序性决定时使用。
- `会议要求〔单位〕会同有关方面进一步论证完善。`

## 责任分工句

- `由〔牵头单位〕牵头，〔配合单位〕配合，细化任务清单，明确时间节点。`
- `〔责任单位〕负责做好〔任务〕，并及时向〔单位〕反馈办理进展。`
- `各有关单位按照职责分工做好〔动作〕。`仅在源材料本身以“各有关单位”作为共同责任主体，且没有逐单位分工时使用；存在逐项分工时必须一项行动一句，不得聚合。
- `对需要上报、审批、备案的事项，由〔责任单位〕按〔具体程序〕办理。`

只有源材料明确“任务清单、时间节点、反馈、上报、审批、备案”等要求时，才使用相应句式。

## 组合与节奏

- 同一议题不必配齐“会议认为、会议指出、会议强调、会议要求”。每个引导词都应承担不同功能。
- 结论已经明确时，可先用短句写结论，再写责任动作和程序；不要用长篇背景冲淡结论。
- 连续两句主语和动作相同，可合并重复成分；证据强度不同的内容不得合并。
- 一句承载多个单位、动作、时限和条件时，按行动链拆为两句，并保持各项对应关系。
- “此外、同时、进一步、因此”只在材料逻辑确有并列、递进或因果时使用，不作机械过渡。
- 同一单位、文件和项目全篇使用统一称谓，不为避免重复而轮换近义说法。
- 并列项目按材料实际数量写，不强凑三项；具有独立约束意义的项目不得为简短而合并。
- 没有新事实、新结论或新动作时，不另加“确保取得实效、推动再上新台阶”等通用结尾。

## 自然语言转换

| 会议记录中的说法 | 可采用的纪要口径 | 使用条件 |
|---|---|---|
| 这个方案大体没问题，但还得改 | `会议原则同意该方案，由〔单位〕根据会议讨论意见修改完善。` | 必须确认这是主持人归纳或会议结论 |
| 改完还要报上面审 | `修改完善后按程序提交〔机关或会议〕审议。` | 原文已明确提交对象或程序 |
| 这次先不定 | `会议决定暂缓研究该事项。`或`该事项暂未形成结论。` | 区分明确暂缓与没有归纳 |
| 这个不是甲局做，乙局牵头 | `会议明确，由乙局牵头办理。` | 同时在台账保留责任排除信息 |
| 大家回去抓紧办 | `会议要求抓紧推进相关工作，责任主体〔待核〕。` | 必须先确认属于会议最终归纳；不得把“大家”推定为有关单位，正式定稿前核定责任主体 |
| 下月底前拿出修改稿 | `由〔单位〕于〔具体日期或月份〕前形成修改稿。` | 先根据会议日期准确换算；无法确定则标为待核 |
| 这个问题以后再专题研究 | `会议明确，该事项另行专题研究。` | 不得改成已经同意实施 |
| 方案可以，但合法性审查做完再发 | `会议原则同意该方案，完成合法性审核并按程序修改完善后印发。` | 前置条件不得删除 |

转换时先问三件事：

- 这句话是谁说的，是否代表会议最终归纳。
- 结论、责任、动作、时限和程序分别是什么。
- 是否含否定、条件、范围或暂缓含义。

## 公开版改写句

以下句式只有事实台账中存在对应的明确会议结论，且该结论经公开审查可以公开时才能使用：

- `会议研究了〔事项〕有关工作。`
- `会议要求依法依规、稳妥有序推进〔具体工作〕。`
- `会议强调，要加强〔材料明确的协调事项〕，完善〔材料明确的机制〕。`
- `会议明确，由〔材料明确且可公开的单位〕按职责推进〔具体事项〕。`

不得用上述句式填补删除敏感细节后留下的内容空缺。没有可公开的对应结论时，删除该句或暂停公开，不补写通用要求。

公开版不宜保留：

- 内部争议。
- 个人表态。
- 未公开项目细节。
- 供应商、投标人、案件当事人等敏感信息。
- 具体尚未公开的资金安排和审批路径。

## 督办反馈与后续程序句

以下句式用于纪要中议定事项的落实跟踪，只在源材料有对应要求时使用：

- `由〔牵头单位〕负责跟踪督办，于〔时限〕前将办理情况报〔报送对象〕。`
- `各责任单位于〔时限〕前将落实方案报〔汇总单位〕汇总。`
- `〔办公室/秘书处〕负责纪要议定事项的督办落实，定期通报办理进展。`
- `本纪要印发后，由〔办公室/秘书处〕负责归档，〔公开属性〕。`
- `涉及未公开事项的，不得擅自扩散、对外发布或引用。`
- `对需要上报、审批、备案的事项，由〔责任单位〕按〔具体程序〕办理，办理结果及时报告。`
- `〔牵头单位〕于〔时限〕前形成〔成果形态〕，报〔审批或审议机构〕审定。`
- `建立〔调度/通报/约谈〕机制，〔频次〕调度一次，发现问题及时协调解决。`

执行闭环原则：纪要中凡涉及任务交办、方案调整、协调事项、问题整改、材料报送、公开发布、进一步论证等内容，原则上都应对应责任单位、时限、成果形态或反馈要求。后续要求中宜写明跟踪督办、办理反馈、请示报告、保密管理、材料归档、对外口径等安排，避免会议决定形成后无落实抓手。

## 判断强度与证据匹配

纪要中对工作进展和成效的判断，措辞应与证据强度匹配：

| 强度 | 表达 | 使用条件 |
|---|---|---|
| 1 | 已启动、正在开展 | 只有部署或初始动作 |
| 2 | 有序推进、稳步推进 | 有计划步骤，结果有限 |
| 3 | 取得进展、初见成效 | 有阶段结果或反馈 |
| 4 | 取得明显成效、形成机制 | 有数据、制度或稳定运行 |
| 5 | 重大突破、历史性成就 | 有权威认定、关键指标或行业比较 |

证据不足时下调判断。宁可稳妥，不要拔高。不得把强度 1 的事实写成强度 4 的评价。

## 常见不规范用词对照

| 不规范 | 规范 | 说明 |
|---|---|---|
| 截止 | 截至 | "截止"为动词，"截至"后接时间 |
| 打算 | 决定、拟 | 公文不用口语"打算" |
| 老百姓 | 群众、市民、居民 | 按语境选择 |
| 一把手 | 主要负责人 | 正式场合用规范称谓 |
| 没有着落 | 缺口、尚未落实 | 避免口语化 |
| 差不多 | 基本、大体 | 公文用准确程度词 |
| 赶紧 | 抓紧、尽快 | 避免口语化 |
| 弄 | 办理、处理、落实 | 避免口语化 |

## 避免使用的句式

- `妥否，请批示。`
- `特此报告。`
- `现将有关事项通知如下。`
- `请认真贯彻执行。`
- `经研究，决定批准……`，除非材料明确会议具有相应权限且程序完整。
- `与会人员一致认为……`，除非材料明确有该事实。
- `会议决定、会议批准、会议同意实施` 等强结论词，除非材料能证明权限、程序和会议结论均已明确。
- `经充分讨论，与会人员一致同意……`，除非记录能够证明讨论和一致同意两个事实。
- `取得显著成效、具有重要意义、形成广泛共识` 等评价，除非源材料明确形成该判断。
- `值得注意的是、毋庸置疑、从某种意义上说` 等填充性铺垫。
- `有关方面认为、大家普遍认为、与会人员普遍表示` 等模糊归因，除非记录能够证明主体和范围。
- 连续堆叠“进一步提高认识、进一步压实责任、进一步形成合力”等同构表达，却没有具体对象和动作。
- 为追求语言变化而改写单位、文件、项目、法定术语、结论词和权责限定词。
