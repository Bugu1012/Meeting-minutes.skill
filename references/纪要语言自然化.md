# 纪要语言自然化

本文件用于在会议事实、议定事项和行动链已经锁定后，对纪要作自然、简明、平实的语言处理。目标是减少机械套话和人工智能式平均节奏，不是把正式会议纪要改成个人文章，也不是为了“好听”而提高评价、结论或情绪强度。

## 适用边界

适用于：

- 已由会议记录、转写稿或其他源材料形成的纪要初稿。
- 事实基本可靠，但语言重复、生硬、口号化或模板痕迹明显的纪要草稿。
- 需要在不改变公文语体的前提下压缩套话、改善句段衔接的稿件。

不适用于：

- 尚未建立事实台账、尚未区分讨论与结论的原始记录。
- 需要通过“润色”补足缺失结论、责任、时限或政策意义的稿件。
- 只有纪要成稿而没有源材料，却要求核实事实准确性的任务。

语言自然化不是事实修复。事实不清时使用 `〔待补〕`、`〔待核〕`、`〔待定〕` 或质询式澄清，不用更顺的句子掩盖缺口。

## 处理次序

严格按以下顺序处理：

1. 锁定事实：从纪要初稿回到源材料，标出不可变内容。
2. 校准体例：有本机关近期同类公开纪要时，只提取段落长度、层级、称谓和引导句使用习惯。
3. 扫描机械表达：查找填充语、套话堆叠、模糊归因、同构句、过度排比和通用结尾。
4. 完成初改：保留全部有证据信息，允许合并或拆分句段，不必机械保持初稿形状。
5. 执行自审：检查残留的机械模式和新增事实，形成内部问题清单。
6. 完成二改：只处理自审命中项，不做随机换词和无目的变句。
7. 双向复核：先从改写稿回到源材料核锁定项，再从源材料回到改写稿查遗漏。

任何事实锁定项发生变化，立即恢复原表述并重新处理。不得以“意思差不多”作为放行理由。

## 必须锁定的内容

以下内容不得在语言处理时增删、改强、改弱或用近义词替换：

- 会议名称、会议类型、时间、地点、主持人。
- 议题名称、文件名称、平台名称、项目名称、单位名称和其他专名。
- 日期、数量、金额、比例、序号和范围。
- “研究、听取、审议、传达学习”等议题动作。
- “建议、倾向、原则同意、同意、决定、批准、提交审议、按程序报批”等结论强度。
- 牵头单位、配合单位、责任对象、具体动作、完成时限、完成标准和程序路径。
- “不、不得、严禁、暂缓、不予、另行研究”等否定或限制。
- “在……后、经……后、限于、仅限、至少、全部、唯一、专职、主动权”等条件、范围和权责限定。
- `〔待补〕`、`〔待核〕`、`〔待定〕` 和“采纳状态待核”等不确定性标记。

可使用简表核对：

| 原文定位 | 锁定内容 | 润色前表述 | 润色后表述 | 是否一致 |
|---|---|---|---|---|
| 〔议题或时间戳〕 | 〔结论、责任、时限等〕 | 〔原句〕 | 〔改写句〕 | 〔是／否〕 |

## 体例校准

语言自然化优先服从本机关已经形成的规范体例。用户提供本机关既往纪要，或真实公开样例索引中有同一机关、同一会议类型的近期正文时，可以校准：

- 标题和开头的惯用写法。
- 每个议题通常采用整段还是分层表达。
- “会议指出、会议强调、会议要求”等引导句的使用密度。
- 单位全称、简称、日期、序号和尾部要素的写法。
- 公开版通常保留到什么信息粒度。

体例样例只用于回答“本机关通常怎么写”，不能用于回答“本次会议决定了什么”。样例中的人名、地名、项目、数字、责任单位、政策判断和结论不得迁入本次纪要。样例与源材料冲突时，以源材料和有权核定结果为准。

## 可借鉴的自然化规则

从通用中文自然化写作方法中，只借鉴下列与正式会议纪要相容的规则：

- 删除填充语。删去“值得注意的是、从某种意义上说、毋庸置疑”等不承载新事实的铺垫。
- 直接陈述。能写具体事实、问题、结论或动作时，不先宣告其“重要、关键、深远”。
- 消除模糊归因。“有关方面认为、普遍认为、大家一致认为”必须有记录依据；没有依据就删除或回到真实主体。
- 减少机械排比。不为形式整齐强凑三项，不给每个议题配齐同一组引导句。
- 避免同义词循环。单位、文件、项目和政策术语保持一致，不为避重复而换称谓。
- 控制连接词。“此外、同时、进一步、因此”只在确有递进、并列或因果关系时使用。
- 调整句长。把承载多组责任、条件和程序的长句拆开；相邻短句内容紧密时可合并。
- 删除通用积极结尾。没有具体安排时，不添加“开创新局面、迈上新台阶、取得新成效”等收束语。
- 保留具体细节。不要把具有辨识度的对象、动作和条件压缩成“抓好有关工作”。
- 保留信息而不拘泥于初稿形状。事实覆盖不变时，可以拆开负担过重的长句，也可以合并连续重复的短句。
- 优先恢复清楚的主语和动作。连续出现“要进一步、要持续、要切实”时，回到源材料写明谁做什么；材料没有主体时不得补写。
- 控制段落负担。一个句子同时承载多个责任主体、条件、时限和程序时，应按行动链拆分，避免读者在句尾才找到责任关系。

单个词语或单个长句不当然属于人工智能式表达。应当看同一段是否同时出现套话堆叠、节奏整齐、模糊归因和内容空泛，避免把正常公文表达误删。自然化审查处理的是表达问题，不对文本是否由人工智能生成作鉴定。

## 纪要中的常见机械表达

| 机械表达 | 风险 | 处理方式 |
|---|---|---|
| 每个议题都依次写“会议认为、会议指出、会议强调、会议要求” | 结构整齐但信息重复，容易补写材料没有的判断 | 只保留有独立事实依据和功能的引导句；其余直接写结论或行动 |
| “具有十分重要的意义，发挥至关重要的作用” | 容易夸大意义，且常不承载会议结论 | 源材料没有明确评价时删除；有依据时改为会议形成的具体判断 |
| “进一步提高认识、进一步压实责任、进一步形成合力” | 动作对象和完成状态不清 | 改写为材料已经明确的责任主体、具体动作、时限或程序 |
| “有关部门要高度重视，切实抓好贯彻落实” | 可套用到任何议题，辨识度低 | 保留真实单位和任务；材料没有具体动作时不得自行补写 |
| 连续使用“同时、此外、另外、下一步” | 逻辑关系可能并不存在 | 删除不必要连接词，按事项内在关系分句或分段 |
| 强凑三个并列动词或三个形容词 | 形式压过内容 | 按源材料实际项目数表达，两项就写两项，四项就写四项 |
| 为避免重复把同一单位、项目换成多个称呼 | 可能造成主体漂移 | 专名全篇统一；确需使用简称时先写规范全称并确认简称 |
| 结尾写“确保取得实效、推动高质量发展” | 可能以口号替代实际后续程序 | 有具体动作就写动作；没有新信息时不另加结尾 |

## 句段组织

- 一段集中处理一个议题内的同一类信息，避免把判断、责任和另一个议题揉在一起。
- 先写最终结论还是先写主要判断，应服从本机关惯例和材料逻辑；同一篇内保持稳定，不机械追求变化。
- 结论句宜短，责任动作和前置条件紧随其后。责任链较长时，可分为两句，但不得拆散条件与对应动作。
- 同一主语连续出现时，可以合并重复引导语；不同证据强度的内容不得因合并而混成一个结论。
- 并列事项用顿号、分号或分句表达，标点服从逻辑，不用破折号制造强调效果。
- 相邻句长度完全相同且结构反复时，可调整句序或合并重复成分；不得为了追求节奏而拆碎法定术语和固定名称。
- 公开版压缩时，先删除不宜公开或无必要公开的过程信息，再整理语句；不得以自然化为名掩盖删改范围。

## 禁止采用的通用人性化做法

通用文章写作中的下列方法不适用于正式会议纪要：

- 加入第一人称、个人态度、感受、幽默或情绪。
- 刻意加入跑题、口语停顿、自我修正或不完整句。
- 为表现“有观点”而补写评价、立场或因果判断。
- 用故事、比喻、金句、反问、夸张或宣传性语言增强感染力。
- 通过随机换词、随机拆句或打乱结构制造所谓人类节奏。
- 为降低人工智能检测概率而牺牲规范、准确、完整和可追溯性。

正式会议纪要的自然感来自事实具体、层次清楚、句子松紧合宜和用词稳定，不来自与使用场景不符的个人化表达。

## 改前/改后对照示例

以下示例仅用于锚定自然化方向，不作为本次会议的事实来源。改后示例中的〔占位符〕表示应由源材料填入的具体内容。

| 改前 | 问题 | 改后 |
|---|---|---|
| 会议指出，当前我单位工作面临新形势新任务新挑战，全体干部职工要进一步提高政治站位，统一思想认识，凝聚工作合力。 | 意义膨胀+抽象词堆叠+无具体对象和动作 | 会议指出，〔具体事项〕存在〔具体问题〕，需要〔具体对象〕在〔时限〕前完成〔具体动作〕。 |
| 会议强调，要充分认识做好此项工作的重要意义，切实增强责任感和紧迫感，以更高标准、更严要求、更实举措推动各项工作落地见效。 | 三段式包装+空泛口号+动词无宾语 | 会议强调，〔责任单位〕要于〔时限〕前完成〔具体任务〕，〔配合单位〕做好〔具体配合事项〕。 |
| 会议要求，各有关部门要高度重视，加强组织领导，强化协调配合，形成工作合力，确保各项任务圆满完成。 | 模糊归因+万能结尾+无责任主体 | 会议要求，由〔牵头单位〕牵头，〔配合单位〕配合，于〔时限〕前完成〔任务〕，并将完成情况报〔报送对象〕。 |
| 会议认为，该方案的出台具有十分重要的意义，标志着我市相关工作迈上了新台阶，开创了新局面。 | 意义膨胀+公式化结尾+无证据支撑 | 会议原则同意该方案，由〔牵头单位〕根据会议讨论意见修改完善后按程序报批。 |
| 会议听取了有关情况的汇报，听取了有关工作的汇报，听取了有关事项的汇报。 | 机械重复+无信息增量 | 会议听取了〔单位〕关于〔事项一〕、〔事项二〕和〔事项三〕情况的汇报。 |
| 会议听取了关于安全生产工作的汇报。会议指出，安全生产工作十分重要。会议强调，要高度重视安全生产工作。会议要求，要切实抓好安全生产工作。 | 四句同义重复+无具体对象和动作 | 会议听取了〔单位〕关于安全生产工作的汇报。会议要求，由〔责任单位〕于〔时限〕前完成〔具体排查或整改任务〕，〔配合单位〕做好〔配合事项〕。 |

使用规则：

- 改后示例只提供方向，不提供本次会议事实。
- 如果源材料确实只有"要高度重视"这类表述，且无法从材料中找到更具体的对象和动作，则保留原表述并列入未验证项，不用改后示例的占位符强行替换。
- 自然化的目标是让有事实的内容表达更清楚，不是用占位符制造虚假的具体性。

## 两遍审校

第一遍完成初改后，在内部回答：

1. 哪些句段仍同时存在空泛评价、机械排比、模糊归因或连接词堆叠。
2. 哪些句子仍看不清责任主体、动作、条件或程序。
3. 改写是否新增了源材料没有的事实、名称、数字、日期、评价或因果。
4. 改写是否删掉或弱化了否定、条件、结论强度、权责限定和不确定性标记。
5. 是否为了避免重复而把同一专名换成了不同称呼。

第二遍只处理上述问题。没有问题的句子不动，不能为了显得经过润色而改写。完成后使用 `assets/纪要语言复核表.md` 复核；复核表中的事实保真硬项有一项为“否”，即退回初稿重新处理。

## 复核清单

语言处理后逐项回答：

- 是否先完成事实锁定，再开始润色。
- 是否删除了不承载事实的开场、过渡和通用结尾。
- 是否减少了连续堆叠的“会议认为、指出、强调、要求”。
- 是否把模糊归因改回有证据的主体，或在无依据时删除。
- 是否保留了每个具有辨识度的对象、动作、条件和程序。
- 是否避免强凑三项、同义词循环和连接词堆叠。
- 是否保持中性、庄重、平实，未加入第一人称和个人评价。
- 专名、数字、否定、条件、结论强度、责任、时限和程序是否与润色前完全一致。
- 是否重新执行从纪要回源材料和从源材料回纪要的双向检查。

硬性判定：只要润色造成一项事实漂移、结论升级、责任错配、条件遗漏或不确定性消失，即为不通过；语言更顺不能抵消该错误。

方法来源和适配边界见 `自然化方法来源与适配.md`。
