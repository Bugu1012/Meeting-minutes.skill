 # 版式与字体
 
 本文件提供会议纪要相关的版式和字体参考。版式要求以本机关现行公文制度为准，本文件只提供 GB/T 9704-2012《党政机关公文格式》的常见口径。各机关可能有自己的版式制度，起草和审查时应优先服从本机关规定。
 
 ## 字体字号
 
 | 要素 | 字体 | 字号 | 说明 |
 |---|---|---|---|
 | 纪要标题 | 小标宋体 | 2 号 | 居中排布 |
 | 正文 | 仿宋_GB2312 | 3 号 | 主体文字 |
 | 一级标题（一、） | 黑体 | 3 号 | 议题标题 |
 | 二级标题（（一）） | 楷体_GB2312 | 3 号 | 议题下分层 |
 | 三级标题（1.） | 仿宋_GB2312 | 3 号 | 具体条目 |
 | 四级标题（（1）） | 仿宋_GB2312 | 3 号 | 条目下分层 |
 | 发文字号或期号 | 仿宋_GB2312 | 3 号 | 六角括号〔〕 |
 | 抄送机关 | 仿宋_GB2312 | 4 号 | 版记部分 |
 | 印发机关和日期 | 仿宋_GB2312 | 4 号 | 版记部分 |
 | 页码 | 半角宋体 | 4 号 | 版心下边缘 |

 ## 成文日期与文号
 
 - 成文日期：阿拉伯数字全称，如"2026年7月27日"，不编虚位。
 - 发文字号：机关代字+六角括号〔〕+年份+序号+号，如"×政纪〔2026〕5号"。
 - 纪要期号：部分机关使用"第×期"标注，按本机关制度处理。
 
 ## 结构层次序数
 
 ```
 一、第一层次（黑体）
   （一）第二层次（楷体_GB2312）
     1. 第三层次（仿宋_GB2312）
       （1）第四层次（仿宋_GB2312）
 ```
 
 严格按顺序使用，不跳级。
 
 ## 纪要特有版式说明
 
 - 纪要标题通常采用"会议名称+纪要"合成式，如"第×次常务会议纪要""××专题会议纪要"。
 - 纪要一般不套"关于……的纪要"标题格式。
 - 纪要正文后默认不单列落款和印发信息；尾部要素（出席、列席、记录、整理机关、整理日期、公开属性）按本机关制度处理。
 - 版记中的主送、抄送、审核等项按本机关制度取舍，不视为所有纪要通行必备格式。
 - 正式印发稿的发文字号、期号、主送范围、印章和印发机关等版式项目，按本机关制度和现行公文格式规则处理。
 
 ## 使用边界
 
 - 本文件只提供版式参考，不提供本次会议事实。
 - 版式问题不影响事实审查结论；版式不规范属于一般问题，不升级为严重问题。
 - 用户未要求正式排版时，默认输出 Markdown 文本即可，不必模拟版式。
 - 用户要求 Word 导出或正式排版时，按本机关制度和本文件参数处理。
