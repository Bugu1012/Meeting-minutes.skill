# 资料导航

本技能的资料采用“主文件简洁、参考文件分层”的方式组织。处理简单起草或审查时，可以只读主技能文件；处理复杂纪要、公开版纪要、会议记录转纪要、样例仿写时，按本导航加载对应资料。

## 使用顺序

1. 先读 `规范依据.md`，确认当前任务涉及的公文处理、格式和公开审查边界。
2. 再读 `文种边界.md`，确认是否确实应该使用纪要。
3. 继续读 `正文结构.md`，选择常务会议、专题会议、办公会议或议事协调会议结构。
4. 起草时读 `句式库.md`；初稿事实锁定后读 `纪要语言自然化.md`。需要了解自然化方法来源、适配边界或维护规则时，再读 `自然化方法来源与适配.md`；审查时读 `要素与审查清单.md`。
5. 会议尚未召开、用户需要记录重点时，读 `会前沟通与记录提示.md` 并生成定制提示卡。
6. 从会议录音转写稿、平台逐字稿、流水记录或口语化笔记生成纪要时，读 `会议转写稿处理.md`。
7. 建立事实台账、消解指代和冲突、执行原文回查时，读 `事实台账与证据回查.md`。
8. 涉及公开发布、内部争议、个人信息、商业秘密、执法办案信息时，必须读 `公开脱敏与风险.md`。
9. 需要公开样例时读 `样例索引使用说明.md`，再查 `真实公开样例索引.csv`。
10. 事实缺口无法靠材料或资料核实时，且会影响文种、安全、程序或结论强度时，读 `grill-me澄清机制.md`。
11. 维护或迭代本技能时，可读 `开源技能参考借鉴.md`，但不要把开源技能当作当前会议纪要的事实或格式规范依据。
12. 需要直接套用版式时，从 `assets/` 选取模板。

## 资料文件

| 文件 | 用途 |
|---|---|
| `规范依据.md` | 汇总现行公文处理、格式和政府信息公开审查依据，以及使用边界。 |
| `文种边界.md` | 判断纪要适用范围、不适用范围、行文方向和文种混用风险。 |
| `正文结构.md` | 提供四类纪要的正文结构、层级和标题公式。 |
| `句式库.md` | 提供常用公文句式，避免口语化、宣传化和越权化表达。 |
| `纪要语言自然化.md` | 在事实锁定后删除填充语、模糊归因和机械排比，调整句段节奏，并防止润色造成事实漂移。 |
| `自然化方法来源与适配.md` | 记录公文写作与文本自然化方法的来源、采用项、禁用项和两遍审校规则。 |
| `要素与审查清单.md` | 提供起草前事实清单、成稿后审查清单、问题分级。 |
| `会前沟通与记录提示.md` | 在会议召开前确认纪要目标，按议题生成记录重点和散会前核对项。 |
| `会议转写稿处理.md` | 规定从转写稿、逐字稿、流水记录整理纪要时的清洗、事实分层和结论强度控制。 |
| `事实台账与证据回查.md` | 规定证据单元、冲突处理、自然语言消歧和双向回查。 |
| `公开脱敏与风险.md` | 处理公开版、内部版、脱敏版、敏感信息和程序风险。 |
| `样例索引使用说明.md` | 说明真实公开样例索引的字段、筛选口径和使用边界。 |
| `grill-me澄清机制.md` | 规定何时用 grill-me 向使用者逐问确认，以及何时不打断。 |
| `开源技能参考借鉴.md` | 记录从 GitHub 会议纪要和正式文书技能中借鉴的流程、安全边界和维护注意事项。 |
| `真实公开样例索引.csv` | 公开政府常务会议纪要索引，共四百四十七条，其中二百三十四条为正文结构命中；当前不覆盖其他三类会议纪要。 |

## 模板文件

| 文件 | 用途 |
|---|---|
| `assets/纪要起草模板.md` | 从会议材料起草纪要。 |
| `assets/纪要审查模板.md` | 对已有纪要做问题审查和修改建议。 |
| `assets/会议记录转纪要模板.md` | 把流水账式会议记录整理为纪要。 |
| `assets/会前记录提示卡.md` | 根据具体议题生成可在会中直接填记的提示卡。 |
| `assets/议定事项台账模板.md` | 建立源材料片段到纪要表述的证据映射。 |
| `assets/公开版脱敏模板.md` | 只承载可公开的纪要净稿，不含审查记录、原文映射或内部提示。 |
| `assets/内部核验附注模板.md` | 将公开前审查、脱敏映射、未验证项、候选核定项和处理记录保存为与公开净稿物理分离的内部文件。 |
| `assets/纪要语言复核表.md` | 对照初稿、源材料和自然化稿，检查语言是否顺畅且未发生事实漂移。 |

## 样例使用原则

- 只借鉴公开样例的结构、层级、句式和责任分工表达。
- 不复制样例中的具体事实、数据、项目、地名、人名或政策结论。
- 优先使用“正文结构命中”的样例。
- “访问错误”“待人工复核”“仅元数据可见”条目只能作索引线索，不能作正文样例。
