# 样例索引使用说明

## 索引来源

`真实公开样例索引.csv` 收录公开政府网站和政府政策文件库中的常务会议纪要资料，共四百四十七条。其中二百三十四条标记为“正文结构命中”，适合作为常务会议纪要的结构、句式和议定事项表达参考。当前索引不覆盖专题会议纪要、办公会议纪要和议事协调会议纪要，不得据此声称四类样例均已收集。

## 字段说明

| 字段 | 含义 |
|---|---|
| 序号 | 去重后的索引编号。 |
| 标题 | 公开页面标题。 |
| 发布日期 | 页面或列表显示的发布日期。 |
| 来源网站 | 政府网站名称。 |
| 网址 | 公开页面地址。 |
| 来源栏目 | 采集时对应的公开栏目或检索入口。 |
| 证据类型 | 判断其为纪要资料的依据。 |
| 结构线索摘录 | 预留的结构线索字段；当前批次为空，不应作为筛选依据。 |
| 正文验证 | 对页面正文可用性的验证结果。 |
| 正文验证说明 | 正文中可用于判断结构的片段，或该条不作为正文样例的原因。 |
| 采集说明 | 资料采集整理批次说明。 |

## 验证状态

| 状态 | 用法 |
|---|---|
| 正文结构命中 | 可作为高质量结构样例。 |
| 仅元数据可见 | 可确认存在该纪要，但不作为正文样例。 |
| 待人工复核 | 只作线索，使用前需打开页面核验。 |
| 访问错误 | 不作为正文样例，只保留来源记录。 |

## 推荐筛选口径

优先筛选：

- 正文验证为“正文结构命中”。
- 标题含“常务会议纪要”。
- 发布日期较新。
- 来源为政府网站。

排除：

- 标题含“未公开”“情况说明”“模板”“范文”。
- 正文验证为“访问错误”。
- 只显示元数据、附件缺失或旧链接回首页的页面。

## 使用边界

- 可以借鉴“会议议定以下意见”“会议指出”“会议强调”“会议原则同意”等结构句式。
- 不要复制公开样例中的具体事实、数据、地名、人名、项目名或政策结论。
- 不要把地方公开样例当成全国统一格式规范。
- 法规、格式、保密、公开属性等问题需另查当前有效官方依据。
- 专题会议、办公会议和议事协调会议的结构只能依据本技能结构规则、本机关制度和另行核验的真实公开样例，不得假称来自当前索引。
